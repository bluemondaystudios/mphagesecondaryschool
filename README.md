# Mphage Secondary School website

Static, single-page website for Mphage Secondary School (Tafelkop, Limpopo). No build step.

- `index.html` – the page
- `assets/css/styles.css` – styles (colours taken from the school uniform: sky blue, navy, white, with gold from the crest)
- `assets/js/main.js` – mobile menu, active-section nav, gallery lightbox
- `assets/img/` – crest (cropped from the 2026 admissions poster) and optimised photos

Preview locally: `python3 -m http.server` then open http://localhost:8000.
Can be hosted as-is on GitHub Pages, Netlify or any static host.
